# 微信对话知识库

存**对话记录**的地方：跟谁聊过什么、这个人怎么说话、哪些话是雷区、哪些回复管用过。

**注意：这个目录下的东西不进版本库。** `.gitignore` 里写的是 `docs/wiki/*` 全忽略，
只对 `README.md`（本文件）和 `_模板.md` 开了两个例外——里面是真实的人际内容，
跟代码一起提交不合适。

## 怎么组织

**一个人一个文件**，文件名就是会话名，跟程序里的会话对得上：

```
docs/wiki/
  README.md        ← 本文件，进版本库
  _模板.md         ← 空骨架。**程序自动建页时照抄的就是这一份**，里面不能放示例
  玄子.md          ← 你聊过的人，一人一页，不进版本库
  小分队.md        ← 群聊也一人/一群一个文件
```

**「画像」要写成能直接用的判断**，不是形容词——「他说随便的时候是真随便」比
「他比较随和」有用一百倍。填好的画像长这样：

```markdown
## 画像

**关系**：friends
**说话风格**：话少，几乎不用标点，急了才连发几条

**说话习惯**：句子短，常用「就这」「行吧」收尾。晚上十一点后回得特别快。
不同意的时候不直说，会先回一个「呃」——那就是要反对了，等他往下说就行。

**雷区**：别提他前任。他加班的时候别问「在干嘛」，问了他会以为你在催。

**有效的**：有事直说别绕，绕了他就回「嗯」。他说「随便」的时候是真随便，
不用追问「真的吗」——问了反而嫌烦。
```

一页分两半：

- **上半是画像**——关系、说话习惯、雷区、称呼。会被不断修正，越用越准。
- **下半是记录**——按时间往下追加，**只往后写，不改旧的**。记的是**双方实际说的话**：
  对方说了什么、我回了什么、后来怎么样。不用逐字全抄，挑有信息量的那几句就行，
  但**标点是语气的一部分，别顺手抹平**（「你最好是。」和「你最好是」不是一句话）。

  ```markdown
  - [2026-09-28]
    - 她：你今天是不是又忘了我跟你说过什么？
    - 我：记得，你先别提示我，让我自己说。
    - 她：你最好是。
    - 结果：我去翻了记录才回，她语气软下来了。
  ```

  （这段只是**格式示例，别照抄进你的页面**——模板里特意不放例子，
  就是因为它会被原样复制到每一个新建的页面上，我之前踩过这个坑。）

**「关系」和「说话风格」两行由程序写**：你在主面板那两行上改，它就更新到这一页的画像里。
别手动删——删了界面那边会回落到全局默认。

## 记什么

值得记的是**下次能用上的东西**：

- 她会因为什么炸、炸之前有什么信号（「你最好是」= 已经在考验你了）
- 哪些话不能说（翻旧账期间提「我早忘了」）
- 哪些回复真的管用过，哪些踩过雷
- 说话习惯：句长、标点、口头禅、什么时间点回得快

**值得记的**：有信息量的原话（尤其是那些能看出语气和潜台词的）、自己当时怎么回的、
后来事情怎么走的。

**不值得记的**：每条消息一字不落地抄（挑重点就行）、一时一地的琐事（"今天吃了火锅"）。

## 谁往里写

我（AI）按对话整理，你随时可以改。**但一页里「记录」那半只增不改**——
记过的事改了，就等于篡改，以后再翻就不可信了。

整理的时候我会：
1. 读你说的情况，或你在界面上看到的对话
2. 把画像那半更新掉（对不上的旧判断直接改）
3. 往记录那半追加一条，带上日期

## 程序怎么用它

**页面是自动建的。** 某个会话第一次要分析时，程序照 `_模板.md` 替它建一页，
标题就是会话名——你不用手动复制改名。已经存在的不动，你手写的内容不会被覆盖。

> 为什么是「第一次分析」而不是「列表里一出现就建」：微信列表里还有订阅号、服务通知、
> 群公告，扫到名字就建会攒一屏空页。真正算「有来有往」的判据是对方发了新消息。

**起草前程序会读这一页**，把「画像」+ 最近 8 条「选择记录」喂给模型，
所以回复会越来越贴这个人。中间那半「记录」不读——会一直往后长，又贵又跑题。

**「选择记录」也是程序自动写的**：你每点一次「填入」或「复制」，就记一条你选了哪条。
这是最准的偏好信号——是行为，不是你自己的评价。

## 边界

别跟程序那条「聊天内容不落盘」搞混——**那条说的是自动截屏抓到的画面，拍完就丢**。
这里存的是**你自己留的**（手写，或者让我按你说的整理），只在你机器上，
`.gitignore` 挡着进不了版本库。两码事：程序不主动记，但你要留，那是你的选择。

**「记录」那半现在要手写**（或者让我按你说的整理）。程序不会自动往里灌——
它只在「选择记录」里写那几行，那几行是你点出来的，不是从聊天里抄的。
